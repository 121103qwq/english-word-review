# 英语单词速记 8.4.1

同一套 Vite + TypeScript 核心输出单文件离线 HTML、Tauri 2 Windows 应用和 Capacitor 8 Android 应用。当前 8.4.1 发布线会在应用启动及打开数据同步设置时检查 GitHub 最新正式 Release；发现更高版本后按当前平台提示打开 HTML、Windows 安装包或 Android APK。检查不会定时运行，网络失败不会阻塞离线学习。8.3 系列的手动多文件同步、Android 原生朗读和通用中文构词推测继续保留；原有三种学习模式、检查背诵和 `weighted-random-v1` 抽题算法保持不变。

## 检查背诵与间隔复习

- 从工具栏手动进入，可检查当前词库全量，或额外加入最多 10 个已经到期的旧词；没有到期旧词时会明确退化为仅本期。
- 每轮混合“英→中”主动回忆与“中→英”完整拼写。首答立即反馈；首错会在至少 5 道其他主队列题后同向补测一次。
- 独立的 `spaced-review-v1` 使用 1、3、7、14、30、60 天固定间隔。到期答对晋级，提前练习不连续晋级，首答错误回到 1 天阶段。
- 长期检查事件和调度随 v4 完整备份及学习进度同步；未完成会话只保存在当前设备，退出后可继续或确认放弃。
- 这是可解释的固定间隔初版策略，不宣称精确复现“艾宾浩斯遗忘曲线”，也不包含通知、FSRS、SM-2、语音识别或个体化参数训练。

## 离线词典与手动词库

- 离线词典由固定提交的 ECDICT 和 Engra 构建，包含中文释义、音标、词形、词频及可靠词根关系。
- 词典按双字符分块、gzip 压缩并内嵌到单文件 HTML；查词、距离 1 纠错和词根推测不访问网络。
- 新词库日期必填，同一天可创建多个 UUID 词库；支持 `,，.。`、换行批量分隔和 Enter 逐行输入。
- 只有完整匹配失败后才给出最多 5 个距离恰好为 1 的建议；未知词可填写中文后作为用户词条提交。
- 单词可按当前词库或全部词库修改中文、词根、音标/读音，并可绑定多个内容寻址 MP3。没有自定义 MP3 时回退到浏览器或系统 TTS。

普通构建不会联网。只有明确更新词典源时才运行：

```powershell
npm run dictionary:refresh
```

固定源版本和生成哈希位于 `src/dictionary/generated/metadata.json`，第三方许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 数据与同步

- 齿轮设置中的“数据同步”直接管理学习进度与内容镜像；GitHub、多个 WebDAV、凭据、保存和立即同步不再跳转到页面外部。
- `english-word-review-v4` 继续保存学习检查点和事件；旧 v2/v3 与辅助 v1 键保持不变。
- 独立 `ContentSnapshotV1`、本地 30 批同步副本和 MP3 保存在 IndexedDB；完整导出包含学习快照、内容快照和音频清单，v7.4.5 兼容导出保持不变。
- GitHub 默认使用私有数据仓库 `121103qwq/english-word-review-data`；还可配置任意数量的 HTTPS WebDAV 镜像。公开代码仓库不保存个人词库、进度、MP3 或密钥。
- 启动和修改词库时不再自动访问云端。点击“选择上传 / 下载”后，每个词库生成一个独立文件，学习进度另存为一个可合并的 v4 事件文件；文件名包含设备编码、地点、分钟、批次和词库标识。
- 左栏只上传用户勾选的本机当前或历史文件，右栏只下载用户勾选的云端文件；同一分钟有本机副本时会标出内容一致、单词相同但进度不同、内容不同或单词不同。
- 下载词库文件时只替换同 ID 词库或增加新词库，不删除其他本机词库；下载进度文件只做事件并集合并，不直接覆盖本机最终计数。旧版整份 `current.json` 仅供另存只读备份。
- 从 8.2.0 升级时，只对精确匹配旧内置 37 词库的活动库执行一次本地迁移：先保留旧库与备份，再切换到 v7.4.6 重构版的 39 词库；自建活动词库不受影响，是否上传由用户手动选择。
- 本机及每个可达镜像按设备与地点保留最新 30 个完整批次。MP3 使用内容寻址并默认不传输，只有用户勾选“同时传输 MP3”时才上传或下载。
- HTML 将同步凭据不加密地保存到当前浏览器并在启动时自动加载；Windows 凭据管理器与 Android Keystore 直接保存服务凭据，不再要求设置或输入额外的应用密码。WebDAV 服务自身需要认证时仍可填写其用户名和服务密码，匿名 WebDAV 可留空。

## 个性化设置与快捷键

- 顶部常驻当前题型菜单与设置齿轮；设置中心包含常规、外观、朗读与反馈、快捷键、设置文件同步及原有数据同步入口。
- Windows、Android、HTML 各自使用独立设置档案。主题、字号、自动朗读、语速、音效、振动和快捷键不会写入词库快照、学习事件、普通导出或内容同步 outbox。
- 快捷键按物理 `KeyboardEvent.code` 保存，每个动作有两个槽位；普通答题、强化、词根、检查背诵、朗读、换词、错词筛选和题型切换均支持重新绑定，冲突时可交换。文本输入时学习快捷键自动暂停。
- 设置文件只在用户点击刷新、上传或下载时访问云端；仅允许应用同平台文件，并按地点优先显示。每个地点在每个启用镜像保留最新 30 份。
- 默认朗读仍为浏览器或系统 TTS，自定义单词 MP3 始终优先。可选 MiMo v2.5 TTS 仅在启用后联网；密钥只从私有 GitHub 数据仓库的固定路径读取并保存在本机，不进入 WebDAV 或设置快照。
- MiMo 音频使用独立 LRU 缓存，默认 512 MiB、上限 3 GiB；请求失败或 6 秒超时时自动回退系统朗读。答题音效附件也使用独立 IndexedDB，单文件上限 2 MiB。

## 开发与验证

```powershell
npm install
npm run check
npm test
npm run package:html
```

单文件 HTML 输出到 `release/html`。

Windows：

```powershell
npm run tauri:build
```

安装版和便携版分别输出到 `release/windows-installer` 与 `release/windows-portable`。

Android（JDK 21、Android SDK 36，最低 Android 8 / API 26）：

```powershell
npm run package:android
```

侧载 APK 输出到 `release/android`。

算法冻结参数、版本升级规则与文献依据见 [docs/algorithm-compatibility.md](docs/algorithm-compatibility.md)。
